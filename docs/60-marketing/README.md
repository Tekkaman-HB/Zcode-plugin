# 60-marketing — 目标说明

## 目标

从市场视角说明产品定位、目标受众、对外文案与发布信息。

## 放什么

产品定位与价值主张、目标受众、发布说明、竞品参考。

## 不放什么

- 内部需求细节 → 00-context/
- 技术实现 → 20-architecture/

## 命名格式

授权后使用简洁中文主题，例如 `产品定位.md`、`发布说明.md`。

## 内容格式

授权后默认包含「受众与场景 / 价值与证据 / 渠道与版本」。

## 访问边界

除非用户明确授权 `60-marketing/`，AI 不得读取、创建、修改、移动、重命名或删除其中任何文件。自动检查只确认路径存在，不打开内容。

## 编写要求

- 明确受众、价值主张、证据、渠道、版本与发布时间；对外表述须与产品事实一致。
- 不把内部实现过程或未经验证的卖点写成发布事实。
