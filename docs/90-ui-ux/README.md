# 90-ui-ux — 目标说明

## 目标

说明界面结构、页面清单与交互约定。

## 放什么

信息架构、页面/屏幕清单、交互模式、组件约定。

## 不放什么

- 产品业务流程与验收 → 10-product/
- 对外营销文案 → 60-marketing/

## 命名格式

使用简洁中文主题，例如 `页面清单.md`、`交互模式.md`。

## 内容格式

默认包含「用户目标与信息架构 / 状态与交互 / 无障碍与验收」。

## 编写要求

- 围绕用户目标、信息架构、页面状态、交互规则、错误/空状态和无障碍要求编写。
- 记录当前设计约定，不按版本堆叠像素级修改流水；50/80 中的历史方案按统一收敛确认流程处理，不从本目录直接发起归档。
- 设计系统的逐值规范（oklch 令牌/圆角/阴影/动画）以 `src/ui/webview/styles.css` 与根 CLAUDE.md 的设计系统条目为权威，本目录记录使用约定与验收口径。
