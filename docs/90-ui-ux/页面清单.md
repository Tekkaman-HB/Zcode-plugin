# 页面清单

## 用户目标与信息架构

单面板应用（VSCode 右侧栏 webview），纵向结构自上而下：

| 区域 | 内容 | 状态 |
| --- | --- | --- |
| 标题栏 | 会话标题 + 历史（时钟）/ 新建（加号）按钮 | 当前 |
| 横幅 | 仅环境缺失常驻；失败走错误气泡 | 当前 |
| 消息流 | 用户/助手消息、工具卡、交互卡、思考指示器、错误气泡 | 当前 |
| 欢迎门 | 登录门 / 空会话欢迎页（建议词） | 当前 |
| 排队条 | 队列条目（全文 + 立即发送 + 删除） | 当前 |
| 附件行 | 附件芯片（缩略图 + 移除） | 当前 |
| 输入区 | 文本框 + 控制栏（附件/@/模型/齿轮 · 环/模式/发送） | 当前 |
| 弹层 | 模型/模式/齿轮/历史/斜杠/@ 六类 popup + lightbox | 当前 |

## 状态与交互

四主题（亮/dark/HC/HC-light）；空态、未登录态、启动态、错误态各有专属呈现（详见 `交互模式.md`）。

## 无障碍与验收

交互卡 role=dialog + 键盘全操作；`npm run theme-check` 守护布局契约；验收走查见 `../10-product/验收标准.md`。
