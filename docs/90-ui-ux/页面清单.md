# 页面清单

## 用户目标与信息架构

VSCode 右侧栏单面板，以本机 Codex 插件 26.1021.22027 的布局为参照，保留 ZCode 品牌与实际能力。

| 区域 | 内容 |
| --- | --- |
| 聊天导航 | 返回、标题/聊天操作、最近聊天、设置、新建聊天 |
| 横幅 | 环境缺失提示；服务失败显示错误与重试入口 |
| 消息流 | 右侧用户气泡、助手正文、可展开工具摘要、代码复制、diff、权限/问答与思考状态 |
| 欢迎页 | 登录门或空会话建议，处于文档流内 |
| 队列 | 待发送文本、立即发送与移除 |
| 输入状态行 | 本地模式、ZCode 套餐额度入口 |
| 一体式输入框 | 附件与文本区、底栏左侧附件菜单/权限，右侧上下文/模型与强度/发送或停止 |
| 浮层 | 聊天操作、附件、模型与强度、四种权限模式、设置/MCP、历史搜索、上下文、额度、slash/@ |
| 模态 | 附件预览、手机配对；带焦点约束与关闭恢复 |

## 状态与交互

支持亮色/dark/HC/HC-light，跟随 VSCode 字体与主题变量；窄侧栏对模型标签省略，保留操作入口。空态、未登录、启动、失败、流式、等待应答与后台任务均使用真实状态。

产品不展示没有 ZCode 后端能力的 Codex 云端或听写入口。权限名称继续表达 ZCode 的计划/变更前确认/自动编辑/完全访问四种不同语义。

## 无障碍与验收

操作 SVG 共用图标系统，按钮提供名称与状态；菜单支持键盘与焦点恢复，模态支持 Tab/Esc。人工预览与自动回归都加载真实构建产物，不维护独立的静态组件副本。
