# 交互模式

## 用户目标与信息架构

面板内全部交互模式的约定清单；设计系统逐值规范以 `src/ui/webview/styles.css` 为权威。

## 状态与交互

- 权限卡：选项语义排序（allowOnce→allowAlways→deny→denyAlways→custom）、编号行 + 数字键直选、↑↓/Tab/Enter 导航、Esc=拒绝、拒绝可附反馈（Enter=以反馈提交）、AskUserQuestion 单题表单/多题翻页向导（未答完禁提交）、subagent 徽章。
- 用户输入卡：单题向导、单选点选自动推进（末题提交）、自定义回答行、选项 preview、Esc 返回/取消。
- 交互焦点队列：多卡排队 tab 可点切换（N/M），一次亮一张；草稿保持（重渲染不丢已答）。
- 弹层：锚点定位（下半屏向上弹）、mousedown 判外点关闭、slash/@ 弹层 ↑↓/Enter/Tab 键盘导航。
- 输入框：Enter 发送 / Shift+Enter 换行 / IME 组合期不提交；空输入 + 运行中 = 停止态按钮；附件与 @ 引用改变发送供能。
- 工具卡：默认展开、用户折叠记忆跨流式保持、Edit→diff 红绿、Write→全绿新文件。
- lightbox：Esc/点背景/× 关闭；图片 img、PDF/HTML iframe。

## 无障碍与验收

交互卡 dialog 焦点管理（队首切换才抢焦点）；`prefers-reduced-motion` 全局降级；theme-check 断言覆盖布局回归。
