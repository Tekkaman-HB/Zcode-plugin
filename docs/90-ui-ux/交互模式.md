# 交互模式

## 用户目标与信息架构

导航、输入、消息、菜单与模态共用 Codex 插件式视觉规则。设计令牌以 src/ui/webview/tokens.css 为权威；content.css 管内容组件，styles.css 管入口与布局。

## 状态与交互

- 导航：最近聊天/返回打开历史搜索，过滤后恢复所选会话；聊天操作提供新建、复制对话与桌面端打开。设置保留手机配对、MCP、命令与失败重试。
- MCP：清单保留启动失败或已退出的本地服务，未连接项置顶并显示红灯与“未连接”；有实时进程的服务显示绿灯与“已连接”。远程 HTTP 服务缺少会话级连接状态时显示灰灯与“状态未知”，不套用工作区状态。状态同时以文字呈现，未连接项不显示不存在的 pid；重新打开菜单刷新清单。
- 输入：Enter 发送、Shift+Enter 换行、IME 组合期不提交。运行中无内容显示停止，有内容则发送后续消息进入现有队列。服务 ready 表示可发送；未登录、服务未就绪、无会话、空闲无内容或图片落盘中禁用发送，重连就绪后保留草稿并恢复发送。
- 附件：加号菜单提供添加文件/图片、@ 引用和命令；粘贴图片仍由宿主落盘，附件发送使用原始路径契约；可移除单个附件。
- 底部 diff：输入框上方展示当前会话已记录的文件数、绿色新增/红色删除及“查看变更”。只读对比会话执行前后快照，覆盖 Edit/Write 和命令写文件，多轮按最终增量合并；原有脏改动不计入，空闲时外部编辑不改变记录。切换/恢复只加载对应会话，清空旧摘要并拒收其他会话迟到结果。点击直接打开“ZCode · 会话变更”原生多文件 diff 标签，一页列出全部会话文件，可展开/折叠并查看红绿差异与前后原文；新增/删除使用空白侧。资源为持久只读快照，关闭侧栏或重新注册文件系统后仍可读取；缺失资源明确报错。二进制保留原始字节交给 VSCode 原生查看器，不计增删行数，能否可视化取决于文件格式与已安装查看器。捕获基线超过 200ms 时显示“正在准备…”扫光反馈。恢复会话优先加载已保存的完整回合与中间检查点；中断后仅展示检查点内已确认的差异，不把之后的工作区状态补入历史。无可审查文件时隐藏整条摘要与查看入口，包括无历史基线、捕获失败和空的部分记录；有可靠差异的部分记录保留范围标注，不回退工作区 HEAD diff。
- 用量入口：不展示“本地模式”标签或预留状态行。套餐用量圆环移到输入底栏、上下文圆环左侧，同排等高居中；16px 圆环图形、24px 占位、常规 4px 间距，320px 及以下使用占位本身的留白保持等距。套餐数据缺失收起，只有一个窗口时显示单环；点击/键盘打开明细并保持焦点恢复，模型名称可省略但完整名称保留于提示。
- 模型：同一菜单展示模型、窗口大小和当前模型的思考强度。模型按钮仅显示名称、低/中/高和下拉箭头，不显示思考强度闪电标识。所有模型的思考强度统一为同一行的低/中/高，分别选择模型实际支持的最低/中间/最高档；不足三档时缺档置灰，不发送无效值，旧会话的其他档位按距离显示为最近档。选择仍发送模型原始值（例如 GLM 的 low/high/max），左右键在可用档位间移动；四种权限模式在独立菜单，选择仅发送对应原始模式值。
- 菜单：锚点定位并钳制视口；外点关闭，方向键/Home/End 导航，Enter/Space 激活，Esc/Tab 关闭并恢复焦点。slash/@ 使用方向键、Enter/Tab 与 Esc。
- 工具：折叠工具行与活动摘要采用 24px 紧凑节奏；跨助手消息的纯工具调用连续排布，空文本、仅有回合边界的消息不生成占位或复制栏，出现真实正文后恢复正常消息段距。读取/命令用 Codex 方框终端，编辑/写入用铅笔，搜索用放大镜，技能/MCP/通用活动用扳手，图标统一 16px；失败/拒绝保留叉号、停止保留停止图标。同一助手消息内连续两条及以上工具调用收起为一条活动摘要，显示数量与运行/失败状态；Enter/Space 可展开查看各条工具，手动选择跨刷新保持，错误/拒绝默认展开。单条命令按等待/运行/完成/失败/拒绝/停止显示状态文案，具体命令优先于服务端标题，避免 `Bash Bash`；详情显示命令文本及已有输出，运行中输出也可查看。状态图标为 16px，等待/运行使用静态工具语义图标并对状态文字扫光、完成用终端、失败/拒绝用叉号、停止用停止图标。工具详情默认折叠，错误/拒绝默认展开；没有详情时禁用展开。Edit 显示红绿 diff，Write 显示新增文件内容。
- 权限入口与菜单共用语义图标：计划模式=文档，变更前确认=请求批准手掌，自动编辑=终端盾牌，完全访问=叹号盾牌；后三者使用 Codex 原始 SVG。输入框入口图标 16px、按钮点击区域 28px，与旁边加号居中对齐。菜单采用 20px 图标、8px 图文间距和独立 16px 勾选列，图标与勾选在两行文字组成的整行中垂直居中。完全访问的图标、标题、说明与勾选均显示主题警示色；四种模式的标签、描述及实际权限行为保持 ZCode 原语义。
- 首响等待：发送已受理、会话进入运行态后，首个模型事件未到时立即显示“正在处理”扫光文字。真实助手推理或正文出现后接管，等待节点不生成助手消息；不显示秒表、不创建秒表定时器。停止/失败、权限或问答出现、会话切换时清理，恢复运行会话时按当前消息重建。该反馈不代表模型首响耗时缩短。
- 处理动效：思考显示“正在思考”，首响等待、工具执行/活动摘要、当前任务、加载/重连与运行会话标题共用柔和文字扫光；不旋转、不通过透明度闪灭。动画按页面时间对齐，工具刷新重建节点后续播；减少动态效果或强制颜色模式使用静态文字。任务/会话状态点及上下文/额度数值圆环保持静态；等待用户批准或扫码的提示不伪装为模型处理。
- 思考用时：进行中保留“正在思考”扫光；消息结束后摘要显示“用时 6m 12s”等固定时长，取服务端消息 time.completed − time.created（毫秒），恢复历史也使用同一记录，不显示运行中的秒表。缺失/无效时间保留普通“思考过程”，不补造时长。摘要与展开思考正文、强调、引用和代码统一使用弱化文字色，低于最终正文的视觉层级；完成态下方以浅分隔线区分答复，仍可通过键盘展开/折叠。
- 消息：用户消息与助手最终文本可复制；代码块提供语言和独立复制。正文段落保留留白，行内代码随字号缩放；思考箭头使用单层 SVG 与文字行居中。流式期间直接展示 Markdown，已完成块保留 DOM，仅更新未完成尾块；正文前的工具调用不触发每次增量重建整条消息。消息变化同步欢迎空态。model-only、ignored 与 system-reminder 内容不进入显示或复制对话。
- 滚动：向上阅读时消息刷新不拉回底部；“跳到最新”恢复跟随。发送新内容、恢复/新建会话时恢复跟随。
- 权限卡：保持语义排序、数字键/方向键/Enter、Esc 拒绝、拒绝反馈、工具预览与多题向导；不自动放行。
- 问答：单题向导、单选自动推进、末题提交、自定义回答、选项预览与取消；交互队列按 requestId 去重，草稿保持，一次亮一张。
- 任务卡：原生按钮支持展开/折叠，完成后可关闭；关闭记忆按 TodoWrite callId 持久化。列表和底部把手使用同一组 14px 静态细描边图标：进行中为灰色圆环加 4px 中心点，待处理为空心圈，完成为绿色圆圈勾选；当前任务文字保留扫光，不使用大面积实心状态点。
- 预览与配对：Esc/背景/关闭按钮关闭，Tab 留在模态中，关闭恢复触发控件焦点。配对状态刷新保留当前操作与上次二维码。

## 无障碍与验收

主题优先消费 VSCode 变量，语义别名在 body 计算，HC 声明位于 dark 之后。按钮/菜单提供名称、选中/展开状态与焦点样式；减少动效时仍保留文字状态。

npm run theme-check 在真实产物上验证主题、窄栏、键盘、发送/附件、权限/问答、队列、工具折叠、滚动、复制、模态、错误与中英文。CLI 登录、真实模型输出与手机实机配对仍属于集成/人工验收。
