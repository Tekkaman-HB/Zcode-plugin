# 99-archive — 目标说明

## 目标

存放被取代或废弃的历史文档，保留可追溯性。

## 放什么

被取代的旧版文档、废弃方案、历史记录。每份文档须在 frontmatter 标注 `status: historical`/`deprecated`，并声明 `superseded-by`。

## 不放什么

- 当前有效文档 → 对应的标准目录（00–90）

## 命名格式

仅在用户确认收敛清单后，保留原文件名并放入 `YYYY/MM/`。该确认只授权读取本次移动所需的归档说明与目标位置；目标同名时停止并报告，不打开已有目标文件。

## 内容格式

新增归档保留原正文，只补 `status / archived-at / source-path / superseded-by`。已有归档文件不得被日常任务自动更新或重排。

## 访问边界

日常任务和默认审查不读取本目录内容。用户确认 50/80 收敛清单后，只允许完成清单内的新增归档；其他新增或移动仍须用户明确授权。处理已有文件时，用户必须明确指定具体文件和操作。

## 编写要求

- 新归档保留原始内容和相对路径线索，补充归档日期、归档原因、来源目录及 `superseded-by`。
- 归档文档不得继续作为当前事实更新；未经具体授权不得读取、恢复、整理或修改。
