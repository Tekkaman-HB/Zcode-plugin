# 验收标准

## 用户与场景

发布前对插件做端到端验收；每条标准对应可执行命令或可观察行为。

## 流程与规则

- 协议回归：`npm run smoke` 全绿（spawn → 推账户 → 建会话 → 发消息 → 权限应答 → 回合完成 → session/list）。
- 类型与构建：`npm run typecheck`、`npm run build` 零错误。
- 视觉回归：`npm run theme-check` 8/8 断言（四主题令牌互异、HC 优先级、overlay 默认态、composer 可点性等）。
- UI 走查：`npm run ui-preview` 四主题 + 三栏对比无样式破损；中英双语切换文案完整。
- 手工路径：登录/登出即时同步；粘贴图片发送成功（模型可见）；权限卡键盘全程可操作；回合中排队与插队符合预期；上下文环与 30 天用量可读。

## 验收标准

以上全绿 + 手工路径通过即验收通过；任一失败阻塞发版。

## 约束与待确认

- 待确认：性能基线（首帧/流式帧率）是否纳入验收。
