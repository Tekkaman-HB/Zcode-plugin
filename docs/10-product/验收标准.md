# 验收标准

## 用户与场景

发布前对插件做端到端验收；每条标准对应可执行命令或可观察行为。

## 流程与规则

- 协议回归：`npm run smoke` 全绿（spawn → 推账户 → 建会话 → 发消息 → 权限应答 → 回合完成 → session/list）。
- 类型与构建：`npm run typecheck`、`npm run build` 零错误。
- 视觉回归：`npm run theme-check` 57 项检查（四主题/宿主变量、套餐与上下文圆环同排/间距/键盘与缺失收起、窄栏、首响等待/接管/清理、MCP 名称补齐/红绿灰灯/未连接置顶/全失败与恢复、思考落档用时/恢复与展开同色弱化、图标语义/尺寸/整行居中与警示配色、正文段距/字号缩放、工具活动分组/跨消息紧凑行/空部件过滤/Codex 语义图标、含工具的流式 Markdown/稳定 DOM，以及菜单键盘、输入/附件、历史、权限/问答、队列、滚动、复制和模态等）。
- 差异回归：`npm run changes-check` 26 项通过；实际 Git 临时仓库验证当前会话增量/多轮/切换/检查点中断恢复/归属边界、原生多文件 diff 参数、持久只读快照与二进制/缺失错误；`theme-check` 验证底部摘要、键盘入口、四主题/窄栏/中英文和空态；无可恢复 diff 时摘要及查看入口隐藏，有可靠的部分记录时仍可查看。
- 原生 diff：`npm run diff-smoke` 在隔离 VSCode 窗口通过；同一标签显示新增/删除/修改三个文件及红绿差异，前后原文正确、资源不可写，关闭侧栏/重新注册快照文件系统后仍可读取。
- UI 走查：`npm run ui-preview` 四主题 + 三栏对比无样式破损；中英双语切换文案完整。
- 手工路径：登录/登出即时同步；粘贴图片发送成功（模型可见）；权限卡键盘全程可操作；回合中排队与插队符合预期；上下文与套餐额度入口可读。

## 验收标准

以上全绿 + 手工路径通过即验收通过；任一失败阻塞发版。

## 约束与待确认

- 待确认：性能基线（首帧/流式帧率）是否纳入验收。
