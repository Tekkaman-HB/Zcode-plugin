# 业务流程

## 用户与场景

macOS 上的 VSCode 用户，已安装并登录 ZCode 桌面端，希望在编辑器内直接使用 ZCode 而不切换窗口。

## 流程与规则

- 首次使用：安装 vsix → 打开右侧栏 ZCode 面板 →（未登录时点登录，终端完成 OAuth）→ 面板自动预建草稿会话（模型/模式/思考强度立即可用，不产生历史记录）。
- 对话主流程：输入（文字/附件/@引用/斜杠命令）→ 发送 → 流式渲染回复 → 工具调用以卡片呈现 → 回合结束自动校准消息与用量。
- 权限流程：回合内 CLI 发起权限请求 → 面板弹交互卡（选项排序 + 键盘导航）→ 用户裁决 → 继续或拒绝；多个请求按到达顺序排队，一次亮一张。
- 排队规则：回合运行中发送即入队（全文展示，可立即插队或删除），回合结束自动依序发出。
- 会话管理：时钟按钮看历史 → 点击恢复；加号新建；文件夹/配置变化自动重建服务与会话。
