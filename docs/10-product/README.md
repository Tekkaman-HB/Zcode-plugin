# 10-product — 目标说明

## 目标

从产品视角说明：为谁服务、核心业务流程、怎样算验收通过。

## 放什么

用户与角色、业务流程、验收标准、产品路线。

## 不放什么

- 技术实现与架构 → 20-architecture/
- 对外市场文案 → 60-marketing/

## 命名格式

使用简洁中文主题，例如 `业务流程.md`、`验收标准.md`；当前事实文件不加日期前缀。

## 内容格式

默认包含「用户与场景 / 流程与规则 / 验收标准」。按可观察行为描述，不使用开发任务代替产品事实。

## 编写要求

- 用用户、场景、前置条件、主流程、异常流程和可观察验收结果描述产品事实。
- 不写代码改动过程，不把任务完成清单当产品需求。
