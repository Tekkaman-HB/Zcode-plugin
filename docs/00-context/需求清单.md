# 需求清单

## 背景与目标

以用户可感知的能力组织当前需求；每条需求对应可观察行为。

## 当前事实与范围

- 会话：新建（默认模式可配）、恢复历史、草稿会话（面板打开即预建，不污染历史）、停止运行中回合、排队发送与插队。
- 消息：流式输出（思考中指示器 + 增量渲染）、markdown 渲染、工具卡片（diff/命令/文件清单/问答摘要）、错误气泡。
- 权限：CLI 发起权限请求时弹交互卡——选项语义排序、数字键直选、Esc 拒绝、拒绝可附反馈、bash 放行前缀展示；AskUserQuestion 单题/多题向导。
- 附件：文件选择器（localPath 直传）、图片粘贴（webview dataUrl → 宿主落盘 → localPath）、附件芯片缩略图与 lightbox 预览、`@` 引用工作区文件浏览。
- 配置：模型下拉（分组 + 推理档位）、模式下拉（plan/build/edit/yolo）、齿轮菜单（重试/用量/MCP/命令入口）、上下文用量环与分来源占比。
- 账户：登录（终端 OAuth）、登出、账户状态实时同步（凭据目录监听）、在桌面端打开。

## 约束与待确认

- 已知边界：`session/send` 回合运行中必拒（-32010），宿主侧排队是协议行为的必要补偿，不是可砍功能。
- 待确认：会话删除（delete-session）是否为规划需求——契约与 UI 均未实现，需要产品裁决。
