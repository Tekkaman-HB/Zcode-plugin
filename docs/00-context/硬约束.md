# 硬约束（Constraints）

## Technology

- 仅支持 macOS；CLI 入口 `/Applications/ZCode.app/Contents/Resources/glm/zcode.cjs`（可用 `zcode.appPath` 覆盖）。
- TypeScript strict + noUnusedLocals 必须全绿（`npm run typecheck`）；构建只经 esbuild 双 target（extension cjs/node + webview iife/browser）。
- 运行时依赖仅允许 marked；新增依赖需充分理由。
- 协议知识（事件订阅门槛、附件落盘、patch 陷阱、-32010 排队、stderr 噪声等）以根 CLAUDE.md 为唯一事实源，禁止凭记忆改协议行为。

## Security

- 绝不提交密钥、Token、Cookie；解密后的 apiKey 只用于应答 `interaction/requestProviderRuntimeHeaders`，严禁进日志/遥测/错误消息。
- webview HTML 必须带 CSP（nonce 脚本 + cspSource 资源域）；附件预览仅放行 data:/https: 来源。
- 凭据文件 `~/.zcode/v2/credentials.json` 只读，绝不写入。

## Architecture

- 模块隔离单向依赖：webview 层禁止 import vscode；宿主层禁止 import `src/ui/webview` 内部模块；protocol 层禁止反向依赖 ui；`src/ui/bridge.ts` 保持纯类型零运行时。
- stderr 是诊断噪声，严禁参与 UI 状态机；服务状态只由进程生命周期驱动。
- 单文件 ≤800 行，超出即重构契机；修改代码必须走 GEB 回环（更新文件 L3 头部与所在目录 CLAUDE.md）。
- CLI 的 `stderr`、`mcp/list`（workspace 池恒 disconnected）不可用作 UI 状态源；MCP 名称真相源是 `process/childProcesses`。

## 文档与流程

- 未经用户明确授权，一切搜索与检查排除 `docs/60-marketing/`、`docs/70-research/`、`docs/99-archive/`。
- 重大架构决策必须新增 ADR（`npm run docs:new-adr -- "标题"`）；临时实施记录放 `docs/80-dev/`（YYYY-MM-DD-中文主题.md 三段式）。
