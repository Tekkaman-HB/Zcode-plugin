# 项目简介

## 背景与目标

ZCode 已有桌面端（Electron 应用）与 CLI（`zcode.cjs`，内置 app-server stdio 协议）。本项目把同一能力带进 VSCode：在编辑器右侧栏提供 ZCode 聊天面板，**复用桌面端 OAuth 登录态**（读 `~/.zcode/v2/` 凭据，无需二次登录），通过 CLI 的 `app-server --stdio` NDJSON JSON-RPC 协议驱动完整 AI 会话。

## 当前事实与范围

- 平台范围：仅 macOS（Windows/Linux 未适配）；需本机安装 ZCode 桌面端。
- 能力范围：流式对话、工具调用渲染（Edit/Write diff、命令块）、权限交互卡（语义排序 + 键盘导航 + AskUserQuestion 向导）、附件（图片粘贴落盘 + 文件引用）、模型/模式/思考强度切换、历史会话恢复、上下文用量环、30 天 token 用量、MCP 进程清单、中英双语。
- 协议来源：全部契约逆向自 `zcode.cjs 0.16.9` 并经探针实证，结论的唯一事实源是根 CLAUDE.md——实施时勿重新推导。
- 不做什么：不做独立的账户体系（只复用桌面端）、不做 Windows/Linux、不代理官方 MCP OAuth 站点头（v1 明确返回不支持）。

## 约束与待确认

- 待确认：是否将本项目判定为“包含智能体语义决策路径”（本仓库自身是确定性协议客户端，Agent 决策发生在 CLI 服务端）——若未来判定为是，需补 `00-context/智能体边界规范.md` 等三件套。
