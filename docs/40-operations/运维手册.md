# 运维手册

## 触发条件与影响

面向用户侧排障与发版操作；无服务端运维。

## 操作步骤

- 服务启动失败（横幅/重试入口）：确认 ZCode 桌面端安装路径 → 设置 `zcode.appPath` → 齿轮菜单点重试；连续失败走指数退避（上限 3 次），需手动重试。
- 登录态异常：面板退出登录 → 终端重新 `zcode login` → 凭据落盘后自动同步（约 500ms 去抖）。
- 会话卡死（指示器常亮超 2 分钟）：busy 看门狗 120s 强制解锁；仍异常则新建会话（全新生命周期复位）。
- 发版：`npm run package` → 安装 vsix 走一遍 `验收标准.md` 全项。

## 成功信号与回滚

- 成功信号：服务状态 ready、消息收发恢复、`npm run smoke` 全绿。
- 回滚：回退到上一版本 vsix；本插件不改桌面端状态，回滚无残留。
