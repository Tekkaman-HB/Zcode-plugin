# 40-operations — 目标说明

## 目标

说明如何部署、观测、处理故障与日常运维。

## 放什么

环境配置、监控告警、运维手册（runbook）、故障与排障记录。

## 不放什么

- 本地开发命令 → 30-engineering/命令清单.md
- 产品路线 → 50-planning/

## 命名格式

使用简洁中文主题，例如 `环境说明.md`、`运维手册.md`、`监控告警.md`。

## 内容格式

默认包含「触发条件与影响 / 操作步骤 / 成功信号与回滚」。纯环境说明可按环境分组，但必须说明适用范围。

## 编写要求

- 运维文档写明适用环境、触发条件、影响、前置检查、操作步骤、成功信号、回滚和升级路径。
- 命令必须可执行且避免泄露密钥；故障时间线可以归档，稳定处置方法必须提炼到运维手册。
