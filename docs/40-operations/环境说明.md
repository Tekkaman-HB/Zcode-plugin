# 环境说明

## 触发条件与影响

本插件无服务端部署；运行环境即用户本机（macOS + VSCode + ZCode 桌面端）。本文记录运行期依赖的本地环境。

## 操作步骤

- 必需：ZCode 桌面端（默认 `/Applications/ZCode.app`，可用 `zcode.appPath` 覆盖）；桌面端已登录（`~/.zcode/v2/credentials.json`）。
- Node 解析链：`zcode.nodePath` 配置 → PATH 中的 node → VSCode 内置 Node（ELECTRON_RUN_AS_NODE）。
- 账户数据（只读）：`~/.zcode/v2/` 下 credentials.json / setting.json / provider_config.json；变化由目录监听自动同步。
- 插件设置：`zcode.appPath` / `zcode.nodePath` / `zcode.defaultMode`（build/edit/plan/yolo，默认 build）。

## 成功信号与回滚

- 成功信号：面板登录态正确、会话可建立、模型列表完整（含真实上下文窗口如 1M）。
- 回滚：卸载 vsix 或还原设置项；插件不写入任何桌面端文件，无残留。
