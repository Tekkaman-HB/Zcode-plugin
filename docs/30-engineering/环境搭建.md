# 环境搭建

## 适用范围与前置条件

- macOS；Node ≥18（npm）；已安装 ZCode 桌面端并完成登录（`~/.zcode/v2/credentials.json` 存在）。
- 可选：VSCode ≥1.95 用于 F5 调试 Extension Development Host。

## 操作或规范

```bash
npm install          # 安装依赖
npm run build        # esbuild 双 target 产出 out/
```

调试：VSCode 打开本项目按 F5（Extension Development Host），或安装产物 `code --install-extension zcode-vscode-<版本>.vsix`。

协议冒烟需真实登录态（会消耗一次小额模型调用并留下测试会话）。

## 验证与常见问题

- 验证：`npm run typecheck` 零错误；面板能建会话并收发消息。
- 常见问题：未登录时面板显示登录门（终端 OAuth 后自动同步）；ZCode 装在非默认路径 → 设置 `zcode.appPath`；早期开发版（publisher 为 `zcode`）与本插件共存会抢侧栏容器，先 `code --uninstall-extension zcode.zcode-vscode`。
