# 30-engineering — 目标说明

## 目标

让任何开发者（含 AI）能快速搭环境、跑通命令、按规范写代码。

## 放什么

本地搭建、命令清单、编码规范、AI 编码指南。

## 不放什么

- 架构决策 → 20-architecture/decisions/
- 生产环境与运维 → 40-operations/
- 临时问题分析与验证记录 → 80-dev/

## 命名格式

使用简洁中文主题，例如 `环境搭建.md`、`命令清单.md`、`AI编码指南.md`；当前事实文件不加日期前缀。

## 内容格式

默认包含「适用范围与前置条件 / 操作或规范 / 验证与常见问题」。命令清单等参考型文件可按主题分组，但必须给出预期结果。

## 编写要求

- 命令与流程必须可复现，写明前置条件、完整命令、预期结果和常见失败处理。
- 规范使用明确的“必须/禁止/建议”和适用范围；不要保留一次性调试过程。
