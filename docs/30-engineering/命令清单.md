# 命令清单

## 适用范围与前置条件

仓库根目录执行；标 ⚠ 的命令需要本机 ZCode 登录态。

## 操作或规范

| 命令 | 作用 | 预期结果 |
| --- | --- | --- |
| `npm run build` | esbuild 双 target 构建 | out/extension.js + out/webview/* + out/scripts/smoke.js 产出，零报错 |
| `npm run typecheck` | tsc --noEmit（strict） | 零错误 |
| `npm run watch` | 构建监听（保留可读 CSS） | 持续编译 |
| `npm run smoke` ⚠ | 协议冒烟（真实 spawn + 模型调用） | 全部 ✅，回合 completed |
| `npm run ui-preview` | UI 验收：静态服务 + 开浏览器 | 四主题工具条 + 三栏对比页面可交互 |
| `npm run theme-check` | 真实产物 UI 回归 | 52 项检查全绿；覆盖套餐/上下文圆环同排几何/单双环/键盘明细、处理中文字扫光/刷新续播/无秒表和旋转/无障碍回退、底部 diff 摘要/入口/窄栏与首响等待/接管/清理与图标语义/尺寸/整行居中与警示配色、正文段距、活动分组/跨消息紧凑行/空部件过滤/Codex 工具图标、含工具的流式 Markdown/DOM 复用、真实 ready 状态与横排三档；无全局 playwright 时仅静态检查，不能据此声称交互验收完成 |
| `npm run changes-check` | 会话 diff 数据与宿主回归（隔离临时仓库，无模型调用） | 26 项通过；覆盖脏改动排除、多轮合并/隔离/检查点中断恢复、外部编辑/冲突/断档、发送/队列边界、原生多文件命令、快照持久只读/二进制/缺失错误和项目 Git 零写入 |
| `npm run diff-smoke` | 真实 VSCode 多文件 diff 集成验收（本机 VSCode + 全局 Playwright，无模型调用） | 隔离配置/扩展目录启动专用窗口；验证新增/删除/修改文件红绿差异、前后原文、只读及侧栏释放/重新注册，截图 .playwright-mcp/native-session-diff.png；完成后关闭测试窗口 |
| `npm run package` | 打包 vsix | 根目录产出 zcode-vscode-*.vsix |
| `npm run docs:check` | 文档结构校验 | `docs:check passed` |
| `npm run ai:check` | AI 行为合同校验 | 静默通过（无输出即绿） |
| `npm run docs:new-adr -- "标题"` | 建号新 ADR | decisions/ 下产出下一个序号的 ADR 骨架 |
| `codegraph sync` | CodeGraph 索引增量同步 | 索引与磁盘一致 |

## 验证与常见问题

- smoke 卡在"发送 prompt"：检查桌面端登录态与网络；`SMOKE_VERBOSE=1 npm run smoke` 可看事件流。
- theme-check 的 HC 块序检查位于 tokens.css；浏览器使用全局 playwright，优先已有 Chromium 缓存，再使用已安装的 Google Chrome。先 npm run build 确保验收的是当前真实产物。
